# Lekhraj Singh - Cybersecurity Portfolio

A modern, responsive portfolio website showcasing cybersecurity expertise, penetration testing projects, and bug bounty hunting experience. Built with Three.js for interactive 3D background and styled with modern CSS.

## Features

- **3D Interactive Background**: Animated particle system powered by Three.js
- **Fully Responsive**: Mobile-first design that works on all devices
- **Dark Theme**: Professional dark mode with gradient accents
- **Smooth Animations**: CSS animations and scroll-triggered effects
- **Modern Design**: Glassmorphic UI elements with smooth transitions
- **Fast Performance**: Optimized assets and minimal dependencies

## Sections

- **Hero**: Eye-catching introduction with call-to-action buttons
- **About**: Professional summary and key statistics
- **Skills**: Categorized technical skills and security tools
- **Experience**: Timeline of professional roles and projects
- **Projects**: Featured cybersecurity projects and research
- **Contact**: Multiple ways to get in touch

## Technologies Used

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **3D Graphics**: Three.js
- **Icons**: Font Awesome
- **Hosting**: GitHub Pages

## Getting Started

### Prerequisites
- Git
- Modern web browser

### Installation

1. Clone the repository:
```bash
git clone https://github.com/lekhrazz19/lekhrazz19.github.io.git
cd lekhrazz19.github.io
```

2. Open `index.html` in your browser or serve locally:
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx http-server
```

3. Navigate to `http://localhost:8000`

## Customization

### Update Personal Information
Edit `index.html` and replace:
- Name and titles
- About section text
- Contact information
- Project descriptions

### Modify Colors
Edit `styles.css` and update the CSS variables in `:root`:
```css
:root {
    --primary-color: #4169e1;
    --secondary-color: #00d4ff;
    --accent-color: #ff6b9d;
    /* ... other colors ... */
}
```

### Adjust Three.js Scene
Modify `three-scene.js` to customize:
- Particle count
- Colors
- Animation speed
- Camera positioning

## Deployment

This site is ready for GitHub Pages deployment:

1. Push to your GitHub repository:
```bash
git add .
git commit -m "Initial portfolio commit"
git push origin main
```

2. Enable GitHub Pages in repository settings:
   - Go to Settings → Pages
   - Select "Deploy from a branch"
   - Choose "main" branch
   - Save

3. Your site will be live at: `https://lekhrazz19.github.io`
